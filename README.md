# 🎵 Telegram Music Bot (Trivela AI Music)

Современный Telegram-бот для генерации полноценных музыкальных треков с вокалом или инструменталом по текстовому описанию на базе искусственного интеллекта.

---

## 🚀 Возможности

- **Интуитивный пошаговый процесс создания музыки:**
  - 🎙 **Шаг 1: Артист-референс** — популярные исполнители в удобной сетке (Баста, Скриптонит, Oxxxymiron, Kizaru, Big Baby Tape, T-Fest, Miyagi и др.), расширенный каталог с поиском или режим *«Без артиста»*.
  - 🎧 **Шаг 2: Жанры (мультивыбор)** — 14 музыкальных жанров (Поп, Рэп, Рок, Электроника, Фонк, Lo-Fi, Deep House, Синтвейв и др.). Обязательный выбор от 2 жанров для создания профессионального гибридного звучания.
  - 🎤 **Шаг 3: Формат текста (Lyrics):**
    - 🤖 **Auto:** нейросеть сама сочинит текст и исполнит песню (переход к шагу 4).
    - ✍️ **Свой текст:** генерация трека на собственные стихи или куплеты (генерация стартует сразу).
    - 🎸 **Инструментал:** чистая музыка без вокала (генерация стартует сразу).
  - ✍️ **Шаг 4: Идея для текста** *(только для режима Auto)* — краткое описание сюжета и настроения.

- **Фирменное оформление аудио:**
  - Отправка готового MP3 напрямую в чат с обложкой, текстом трека, жанрами и длительностью.
  - Формат названия трека и подписи:
    - С артистом: `🎶 {Артист} & Trivela | {Название}` *(файл: `{Артист} & Trivela - {Название}.mp3`)*
    - Без артиста: `🎶 {Название}` *(файл: `{Название}.mp3`)*

- **Раздельный баланс пользователей:**
  - **💳 Платные генерации** — купленные пакеты генераций.
  - **🎁 Подарочные генерации** — бесплатные стартовые кредиты, бонусы от администраторов и реферальные награды (списываются в первую очередь).

- **10-уровневая реферальная программа:**
  - Процент вознаграждения растёт от **2% до 20%** по геометрической прогрессии приглашённых авторов ($1, 2, 4, 8 \dots 256$ чел.).
  - **Дробный реферальный баланс (копилка):** точные начисления долей от покупок рефералов.
  - **Автоматический перевод:** как только копилка достигает целого числа ($1.0$), целая генерация автоматически переносится в `🎁 Подарочные`.
  - Чёткое разделение экранов **Профиля** и **Партнёрской программы**.

- **Модуль платежей ЮKassa:**
  - Поддержка карт РФ, СБП, SberPay, Mir Pay, ЮMoney.
  - Автономный фоновый поллер статуса оплат (работает без домена, SSL и открытых портов).
  - Полная защита от повторных начислений (идемпотентность).

- **Панель администратора (`/admin`):**
  - 🔔 **Проверка подписки на канал:** включение/выключение обязательной подписки прямо в главном меню, настройка канала (`@channel` / ID) и пригласительной ссылки.
  - 🎤 **Управление артистами:** добавление новых артистов, изменение порядка (⬆️/⬇️), переключение между популярными и расширенными списками, редактирование стиля нейросети, удаление.
  - 📊 **Системная аналитика:** пользователи, статистика генераций, общая выручка.
  - ⚡ **Баланс API генераций:** проверка остатка кредитов и автоматические алерты при снижении лимита.
  - 📢 **Массовая рассылка:** создание сообщений с HTML-разметкой, предпросмотр и безопасная отправка.
  - 🎁 **Выдача генераций:** моментальное начисление подарочных треков по Telegram ID.
  - 💳 **Управление тарифами:** изменение цен пакетов генераций на лету без перезапуска бота.

- **🔒 Обязательная подписка (Subscription Gate):**
  - При запуске создания музыки бот проверяет членство пользователя в канале проекта.
  - Если пользователь не подписан — отображается экран с кнопкой подписки и кнопкой `✅ Проверить подписку`.
  - Администраторы бота проходят без ограничений.
  - Переключается администратором в один клик.

## 🛠 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone <url_репозитория>
cd music_bot
```

### 2. Создание и активация виртуального окружения
```bash
# Python 3.10+
python -m venv .venv

# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1

# Linux / macOS:
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка окружения (`.env`)
Скопируйте пример файла:
```bash
cp .env.example .env
```
Заполните обязательные переменные:
- `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather).
- `TREBLO_API_KEY` — ключ API провайдера генерации музыки.
- `ADMIN_IDS` — Telegram ID администраторов через запятую (например, `12345678,87654321`).
- `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` — реквизиты магазина ЮKassa.
- `INITIAL_USER_CREDITS` — количество бесплатных стартовых генераций (по умолчанию `1`).
- `GENERATION_COST` — стоимость генерации одного трека (по умолчанию `1`).

### 5. Проверка работоспособности компонентов
Запустите диагностический тест локального окружения:
```bash
python verify_setup.py
```
При успешном прохождении всех тестов отобразится:
`ALL LOCAL COMPONENT CHECKS PASSED!`

### 6. Запуск бота
```bash
python main.py
```

## 👑 Команды администратора

Администраторам доступна команда `/admin`, которая открывает интерактивное меню:
- **🎤 Управление артистами:** просмотр каталога, добавление, удаление, смена позиций в списке, настройка промта стиля.
- **📊 Статистика:** число пользователей, успешных треков, оплат и общая выручка.
- **⚡ Баланс API:** оперативная проверка остатка генераций на аккаунте.
- **📢 Рассылка:** отправка сообщений всем пользователям с предпросмотром.
- **🎁 Выдать генерации:** поиск пользователя по Telegram ID и выдача подарочных кредитов.
- **💳 Тарифы и цены:** редактирование стоимости любого из 4 пакетов (5, 15, 50, 150 треков).
