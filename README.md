# 🎵 Telegram Music Bot (Treblo AI)

Телеграм-бот для генерации полноценной музыки по текстовому описанию (промту) на базе **Treblo API** (модель **Melodia v3**).

---

## 🚀 Возможности

- **Генерация музыки по текстовому описанию (промту):**
  - Поддерживаются любые жанры, стили, инструменты и темпы.
- **Пошаговый процесс создания трека (4 шага):**
  - 🎙 **Шаг 1: Артист-референс** — 10 популярных исполнителей (MACAN, ANNA ASTI, Miyagi & Эндшпиль, Баста, MORGENSHTERN, Король и Шут, Zivert, Скриптонит, INSTASAMKA, Кино/Цой) или режим «Без артиста».
  - 🎧 **Шаг 2: Выбор жанров (мультивыбор)** — сетка из 14 жанров, согласованных с тегами Treblo (`tags`). Обязательный выбор минимум 2 жанров для создания уникального гибридного звучания.
  - ✍️ **Шаг 3: Описание идеи трека** — текстовый промт (сюжет, настроение, детали).
  - ⚙️ **Шаг 4: Формат исполнения** — вокал (AI текст), инструментал (без слов) или свой собственный текст песни.
  - ◀️ **Гибкая навигация:** на любом шаге можно вернуться на шаг назад без сброса диалога.
- **Полноценная интеграция с Telegram Audio:**
  - Отправка готового MP3 трека напрямую в чат с обложкой (thumbnail), исполнителем (`Treblo AI`), длительностью и превью сгенерированного текста.
- **Готовая архитектура для масштабирования:**
  - База данных SQLite (`aiosqlite`) с таблицами пользователей, балансов, истории генераций, рефералов и платежей.
    - Разделение баланса на **платные** (купленные) и **подарочные** (стартовые и реферальные) генерации.
    - Автоматический фоновый приём платежей через **ЮKassa** (работает без домена).
    - **10-уровневая реферальная система:** процент вознаграждения растёт от **2% до 20%** по геометрической прогрессии приглашённых друзей ($2^0, 2^1, 2^2 \dots 2^8$).
- **Развертывание без домена и белого IP:**
  - Бот работает на стандартном Telegram Long Polling (только исходящие запросы в Telegram, Treblo и ЮKassa).
  - Фоновый воркер проверяет статус оплат каждые 15 секунд — домен, SSL и открытие портов **не требуются**.
  - Просто запускаете `python main.py` на любом сервере!

## 🛠 Быстрый старт

### 1. Клонирование / Переход в папку
```bash
cd d:\Dev\music_bot
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv .venv
# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения (`.env`)
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
- `BOT_TOKEN` — токен вашего Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).
- `TREBLO_API_KEY` — ключ API из личного кабинета [Treblo Developers](https://treblo.com/developers/docs).
- `ADMIN_IDS` — Telegram ID администраторов через запятую (например, `123456789,987654321`), которым доступна панель `/admin`.
- `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` — данные магазина ЮKassa.
- `INITIAL_USER_CREDITS` — стартовое количество бесплатных генераций для нового пользователя (по умолчанию `3`).

### 5. Запуск бота
```bash
python main.py
```

## 👑 Панель администратора (`/admin`)

Доступна только пользователям, чьи Telegram ID указаны в `ADMIN_IDS`.

- 📊 **Мониторинг статистики:** общее число пользователей, количество и статус генераций, выручка.
- 0️⃣ **Контроль баланса Treblo API:**
  - Автоматические оповещения администраторам при падении остатка кредитов ниже порога (`< 500`) или при полном исчерпании.
  - Кнопка «Баланс Treblo API» для моментальной проверки остатка кредитов и примерного числа доступных треков.
- 1️⃣ **Массовая рассылка (Broadcast):**
  - Создание сообщений с поддержкой HTML-разметки.
  - Предпросмотр перед отправкой и подсчёт аудитории.
  - Фоновая отправка с защитой от лимитов Telegram (Rate Limiting) и финальным отчётом о доставке.
- 2️⃣ **Начисление генераций:**
  - Поиск пользователя по ID.
  - Начисление любого количества генераций на **подарочный баланс**.
  - Мгновенное уведомление пользователя о подарке.
- 3️⃣ **Динамическая настройка цен:**
  - Выбор любого тарифа (5, 15, 50, 150 генераций).
  - Ввод новой цены в рублях — изменения сохраняются в БД SQLite и сразу видны пользователям без перезапуска бота.
