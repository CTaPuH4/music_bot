# 🎵 Telegram Music Bot (Treblo AI)

Телеграм-бот для генерации полноценной музыки по текстовому описанию (промту) на базе **Treblo API** (модель **Melodia v3**).

---

## 🚀 Возможности

- **Генерация музыки по текстовому описанию (промту):**
  - Поддерживаются любые жанры, стили, инструменты и темпы.
- **Гибкие режимы создания трека:**
  - 🎙 **Выбор артиста-референса:** 10 популярнейших исполнителей (MACAN, ANNA ASTI, Miyagi & Эндшпиль, Баста, MORGENSHTERN, Король и Шут, Zivert, Скриптонит, INSTASAMKA, Кино/Цой) или кнопка «Без артиста».
  - 🎤 **С вокалом (AI текст):** нейросеть сама сочиняет текст и исполняет песню.
  - 🎸 **Без слов (Инструментал):** создание чистой музыки/минусовки.
  - ✍️ **Свой текст:** возможность загрузить собственные стихи для трека.
- **Полноценная интеграция с Telegram Audio:**
  - Отправка готового MP3 трека напрямую в чат с обложкой (thumbnail), исполнителем (`Treblo AI`), длительностью и превью сгенерированного текста.
- **Готовая архитектура для масштабирования:**
  - База данных SQLite (`aiosqlite`) с таблицами пользователей, балансов, истории генераций и рефералов.
  - Подготовленные заделы под реферальную систему, систему баланса и платёжные шлюзы (Telegram Stars, карты, крипто).

## 🛠 Быстрый старт

### 1. Клонирование / Переход в папку
```bash
cd d:\Dev\music_bot
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv .venv
# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения (`.env`)
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
- `BOT_TOKEN` — токен вашего Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).
- `TREBLO_API_KEY` — ключ API из личного кабинета [Treblo Developers](https://treblo.com/developers/docs).
- `INITIAL_USER_CREDITS` — стартовое количество бесплатных генераций для нового пользователя (по умолчанию `3`).

### 5. Запуск бота
```bash
python main.py
```
